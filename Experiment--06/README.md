
# Experiment 6: Bookstore XML Validation

## Aim
To create an XML document for a bookstore and validate it using DTD and XSD.

## Files
- bookstore.xml - Contains bookstore information.
- bookstore.dtd - Defines the allowed XML elements.
- bookstore.xsd - Defines the XML structure and data types.

## Result
The bookstore XML structure can be checked against the DTD
and XSD definitions using an XML validator.
