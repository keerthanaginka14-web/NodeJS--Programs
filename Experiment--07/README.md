
# Experiment 7: Servlet Controller

## Aim
To design a controller using Java Servlet that connects the
shopping cart application with database operations.

## Technologies
- Java
- Java Servlet
- Apache Tomcat
- MySQL or Oracle

## Supported Actions
1. register - Receives a registration request.
2. login - Receives a login request.
3. addToCart - Receives a product ID.

## URL Pattern
/ShoppingCartController

## Note
This is a basic controller example. Database connection,
user authentication, and actual cart operations must be
implemented separately. Deploy the servlet in a compatible
Tomcat web application to run it.
