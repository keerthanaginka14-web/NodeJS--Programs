
# Experiment 8: Session Tracking

## Aim
To explore session tracking mechanisms using Cookies
and HTTP Session.

## Technologies
- Java
- Java Servlet
- Apache Tomcat

## Methods
1. Cookies: Store small pieces of information in the browser.
2. HTTP Session: Store user-related information on the server.

## Program
SessionTrackingServlet.java creates a cookie and an HTTP
session, then reads and displays the stored information.

## Result
The program demonstrates cookie-based and session-based
tracking of a user.

## Note
Deploy the servlet in a compatible Tomcat web application
to execute it.
