
# Experiment 5: Java Database CRUD

## Aim
To develop a Java standalone application that connects to a MySQL database and performs CRUD operations.

## Requirements
- Java JDK
- MySQL Server
- MySQL JDBC Connector

## Operations
1. Create - Insert student records.
2. Read - Display student records.
3. Update - Modify student marks.
4. Delete - Remove student records.

## Note
Create the database using database.sql.
Configure the MySQL JDBC Connector and update the database
credentials locally before running StudentCRUD.java.
Do not upload real passwords.
