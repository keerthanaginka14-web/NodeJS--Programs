
# Experiment 9: Node.js Custom Server

## Aim
To create a custom HTTP server and explore the OS, Path
and Event modules of Node.js.

## Modules Used
- HTTP: Creates the web server.
- OS: Provides operating system information.
- Path: Handles file paths and names.
- Events: Creates and handles custom events.

## How to Run
1. Install Node.js on your laptop.
2. Open a terminal in this experiment folder.
3. Run: node server.js
4. Open http://localhost:3000 in your browser.

## Result
The server displays operating system and file information.
The custom event prints a welcome message in the terminal.
